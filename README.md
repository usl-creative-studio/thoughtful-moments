# thoughtful-moments

Concierge at-home experience kits that let time-poor men make their partner feel genuinely prioritised -- done-for-you setup, done-by-you gesture.

## Setup

1. Clone the repo
   ```bash
   git clone https://github.com/usl-creative-studio/thoughtful-moments.git
   cd thoughtful-moments
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Copy the environment template and fill in your values
   ```bash
   cp .env.local.example .env
   ```

4. Run the development server
   ```bash
   npm run dev
   ```
